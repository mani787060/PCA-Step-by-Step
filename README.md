# PCA Step by Step

-> This project provides a **step-by-step implementation of Principal Component Analysis (PCA)** — one of the most essential techniques in Machine Learning for **dimensionality reduction**       and **feature extraction**.  
-> It explains each component of PCA with code, math intuition, and visualizations.

## Objective:-

-> To understand the working of PCA from scratch and compare manual implementation with **scikit-learn’s PCA** to validate results.
